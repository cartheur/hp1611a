## Differences

- These are not duplicates.
- The `115` page `01611-90909` manual is the later revision and should be treated as the primary repair source.
- The `106` page `01611-90905` manual still includes substantial service content, including troubleshooting and signature-analysis material.
- The main structural sections are broadly the same, but the later manual has newer serial coverage and revised service content.
