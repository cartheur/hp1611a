# HP 1611A Mainframe Figures

Rendered figure-bearing pages from both mainframe manuals.

## Sets

- [service-manual-1980](/home/cartheur/ame/aiventure/aiventure-github/cartheur/hp1611a/docs-classified/mainframe/figures/service-manual-1980): Figures and service-sheet pages from the `115` page `01611-90909` service manual. Use this set first for repair work.
- [operating-and-service-manual-1978](/home/cartheur/ame/aiventure/aiventure-github/cartheur/hp1611a/docs-classified/mainframe/figures/operating-and-service-manual-1978): Figures from the `106` page `01611-90905` combined manual. Use this as a companion set when comparing earlier wording or layouts.

## Notes

- The files are page-based PNG renders from the original PDFs.
- Blank scan pages and obvious section/title-only pages were removed from the exported sets.
- The service-manual set includes troubleshooting sheets, service sheets, block diagrams, adjustment pages, and component-locator pages.
- The companion set includes overlapping material from the earlier combined manual.
